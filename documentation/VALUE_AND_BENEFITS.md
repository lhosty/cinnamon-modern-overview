# Value proposition

## For users

### Faster task switching

The Overview becomes a single place to find windows, launch applications, search and move between workspaces.

### Multiple input styles

The same workflow supports mouse, keyboard, drag-and-drop and swipe gestures.

### Better discoverability

Workspaces, running windows and applications become visible in one coherent interface instead of being spread across separate entry points.

### Traditional workflow remains intact

Outside the Overview, Cinnamon remains a traditional desktop with its normal panel, applets, menu and windows.

### Existing panel becomes more useful

The panel temporarily acts as an Overview dock, so users keep their launchers, grouped window list, tray and applets without introducing a second dock.

## For Cinnamon as a project

### Modern capability without identity loss

The proposal provides a competitive modern workflow while preserving the visual and interaction model that differentiates Cinnamon.

### Reuse of existing architecture

The prototype builds on Cinnamon's existing Overview, workspaces, panels, DND, search providers and keybinding infrastructure.

### Incremental upstream path

Several improvements are valuable independently: spatial navigation, intelligent-hide fixes, panel restoration, swipe stability and animation cleanup.

### No new service dependency

The final prototype does not require a daemon or a project-specific GSettings schema.

## Positioning statement

This should be presented as an **optional or evolutionary native Overview**, not as a replacement for Cinnamon's traditional desktop and not as an attempt to copy another shell.
